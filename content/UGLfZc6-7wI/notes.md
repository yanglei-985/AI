## 摘要
这是一节带同学互动的 Python 现场编程课（字幕从课程中途开始）。前半部分把「回测」写成数学形式：数据集 X = {x1,…,xT}，策略是关于 X 和未知参数 θ 的函数，要用 t 时刻之前的数据估计 θ、再在之后的数据上检验；后半部分用 yfinance/numpy/pandas 下载苹果股价，展示离散与连续的概率分布，讲解「每个 xi 都是随机变量」、密度函数、均值/方差/偏度/峰度等矩，并布置作业：画 (xi, xi+1) 散点图，观察相邻价格是否相关。

## 关键点
- 回测的数学形式：数据 X = {x1,…,xT}，xi ∈ R^d；交易策略是时间的函数，输出买/卖/持有，并含未知参数 θ，所以需要回测。
- 关键原则：用 x_{t−1} 及以前的数据估计 θ，再在 x_t 上决策/检验；把「找参数」和「测试」的数据分开，结果要在测试数据上展示。
- yfinance 下载：`yf.download(ticker, period=..., interval=...)`；返回的是多重索引 DataFrame，不好用，可转成 numpy 数组再用 pd.DataFrame(…, columns=…) 展示。
- numpy vs pandas：numpy 是无标签的多维数组；pandas DataFrame 是二维表格，可用行/列名访问。
- 学习方法：读文档（docstring）、写清参数和返回值；可以让 ChatGPT 提示该用哪个函数，但要自己去读文档理解。
- 离散化价格（高于均值记 high、否则 low）→ np.unique(return_counts=True) → 计数除以总数 = 概率分布 → 条形图。连续取值用直方图（density=True）。
- reshape 的 order：C 按行、F（Fortran 风格）按列；把价格排成「每列一段 5 天路径」用 order='F'。
- 归一化：price / price[0]，让所有路径从同一起点出发，观察相对变化——因为我们赚的是相对变化，而不是绝对价格。
- 每个 xi 都是随机变量：离散时 p1…pm ≥ 0 且和为 1；连续时密度 f(x) ≥ 0 且积分为 1；f(x) 本身不是概率，f(x)dx 才是。
- 描述分布的量：均值、中位数、极差、方差、偏度（左/右偏；注意老师口语里的左右与标准定义相反，标准定义按长尾方向命名）、峰度（尖峰程度）、分位数；它们对应一阶、二阶、三阶、四阶矩。
- 作业：画 (xi, xi+1) 散点图，对多只股票、不同周期（每日、5 天、10 天……）重复，观察相邻价格是否有关系，并据此提出交易策略——下次将引入马尔可夫链。

## 术语表
- **Backtesting（回测）**: 用历史数据检验策略表现，参数只能用之前的数据估计。
- **θ（theta）**: 策略里需要从数据中估计的未知参数。
- **DataFrame**: pandas 的二维表格数据结构。
- **Multi-index（多重索引）**: 有多层行/列标签的索引，处理起来更麻烦。
- **Docstring**: 函数的说明文档，含参数（parameters）与返回值（returns）。
- **Random variable（随机变量）**: 取值带有随机性、由概率分布描述的变量。
- **Probability density function（概率密度）**: 连续变量的分布函数 f(x)，f(x)dx 是落在区间内的概率。
- **Skewness（偏度）**: 分布向左或向右偏斜的程度。
- **Kurtosis（峰度）**: 分布在中心处的尖锐程度/尾部厚度。
- **Moment（矩）**: 描述分布形状的一组量：位置、离散、偏斜、尖峰等。
- **Normalization（归一化）**: 除以起始值，使所有路径从 1 出发，比较相对变化。
